# Билет №4 — тренажёр

Локальное offline веб-приложение для подготовки к экзаменационному билету №4 по режимам формул, карточек, устного ответа, задачи и полного экзаменационного прогона.

## Запуск

```bash
npm install
npm run dev
```

После запуска Vite откройте локальный адрес из терминала, обычно `http://localhost:5173`.

## Режимы

- **Формулы** — быстрый прогон главных формул билета.
- **Карточки** — вопрос/ответ с самооценкой от 0 до 4.
- **Устный ответ** — таймер и чек-лист для каждого блока билета.
- **Задача** — письменное решение задачи `ρ(x,t)=t²` с пошаговой подсказкой.
- **Экзамен** — полный прогон билета на 100 баллов: вопрос №1, вопрос №2, вопрос №3 и задача.
- **Слабые места** — повторение проваленных пунктов и карточек со средним баллом ниже 2.5.
- **Статистика** — прогресс подготовки, лучший/средний/последний результат и слабейший блок.

## Хранение прогресса

Прогресс сохраняется в `localStorage`: попытки, слабые места, оценки карточек, результаты экзаменов и дата последней тренировки. Backend, база данных, авторизация и внешние API не используются.
